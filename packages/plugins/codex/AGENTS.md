# Second Brain — Agent Instructions

When the user wants to record an observation about a team member, use the `ingest` MCP tool.

When the user is preparing for a 1:1, PDI assessment, or feedback session, use the `recall` MCP tool with the person's name and the appropriate context type.

When the user wants to review their team, use `get_team_context`.

When the user wants to search memories, use `search_memories`.

Always respond in the user's language (default: Portuguese).
